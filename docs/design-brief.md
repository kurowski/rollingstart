# Rolling Start — Design Brief

Sep 21, 2026 · @Someone

## Direction

Build toward Linear's level of restraint: a near-black canvas, one disciplined accent color, and density made legible through typography and spacing rather than decoration. The bar isn't "dark mode" — it's software-craft precision, where every element earns its place and nothing moves without a reason.

## Primary references — study these

| Site | What to take from it |
| --- | --- |
| Linear | North star. Near-black canvas, one accent reserved for CTAs/focus states, dense info made scannable via spacing and text-opacity tiers rather than color, zero decorative animation |
| Zed | Same editor-dark restraint; built for people who live in it all day |
| Warp | Dark, block-based, utilitarian — density without noise |
| Supabase | Near-black canvas plus a single accent color, developer-first tone throughout |
| Hex | Worth a closer look at its specific layout and interaction choices |

## Anti-references — avoid these

| Site | Problem to avoid |
| --- | --- |
| Stripe | Generic at this point — no longer a distinctive look |
| Raycast | The reference case for overdone execution of the same idea |
| Mercury | Scrolljacking — never hijack scroll for effect |
| Plausible | Reads like a stock open-source template, not a considered brand |
| Twingate | Forgettable, flat, no point of view |
| Retool | Reaches for the look without nailing it |
| Sentry | Overplayed with illustration/mascot touches — reads as unserious |
| Resend | Right palette, but animation execution is janky |
| Superhuman | Too consumer-polished — not technical enough for this audience |
| Cursor | Leans decorative with gradients |

## Design principles

1. Dark-first, near-black canvas (not pure black) — one disciplined accent color, used only for CTAs, focus states, and brand marks
2. Hierarchy comes from typography and opacity/luminance steps, not from color
3. Hairline, low-contrast borders for structure; minimal shadow
4. Geometric/technical sans, tight negative tracking at display sizes, small dense body text kept legible
5. Motion is subtle and fast (150–250ms), purposeful only — hover states, focus rings, micro-transitions. Never scrolljacking, never parallax hijacking, never animation for its own sake
6. No mascots, no illustration-heavy branding, no cutesy or hard-offset "sticker" decoration
7. Keyboard-first / power-user framing wherever the product allows it
